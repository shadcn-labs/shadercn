## Usage

```tsx
import { WarpBackground } from "@/components/backgrounds/warp";
```

```tsx
<div className="relative h-96 w-full overflow-hidden rounded-xl">
  <WarpBackground preset="aurora" />
</div>
```

## Props

| Prop             | Type                                | Default | Description                                           |
| ---------------- | ----------------------------------- | ------- | ----------------------------------------------------- |
| `preset`         | `"aurora" \| "lava" \| "marble"`    | -       | Optional named preset for params and colors           |
| `params`         | `Partial<Record<string, number>>`   | -       | Shader uniform overrides (`speed`, `swirl`, `shape`)  |
| `colors`         | `Partial<Record<string, string>>`   | -       | Hex color overrides (`color1`..`color4`)              |
| `paused`         | `boolean`                           | auto    | Freeze the frame loop (defaults to reduced-motion)    |
| `pauseOffscreen` | `boolean`                           | `true`  | Pause rendering while scrolled out of view            |
| `maxDpr`         | `number`                            | `2`     | Maximum device pixel ratio                            |
| `className`      | `string`                            | -       | Wrapper CSS class                                     |
| `style`          | `CSSProperties`                     | -       | Wrapper inline styles                                 |
