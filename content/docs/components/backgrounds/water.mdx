## Usage

```tsx
import { WaterBackground } from "@/components/backgrounds/water";
```

```tsx
<div className="relative h-96 w-full overflow-hidden rounded-xl">
  <WaterBackground preset="lagoon" />
</div>
```

## Props

| Prop             | Type                                | Default | Description                                                    |
| ---------------- | ----------------------------------- | ------- | -------------------------------------------------------------- |
| `preset`         | `"abyssal" \| "lagoon" \| "pool"`   | -       | Optional named preset for params and colors                    |
| `params`         | `Partial<Record<string, number>>`   | -       | Shader uniform overrides (`speed`, `size`, `caustic`, `waves`) |
| `colors`         | `Partial<Record<string, string>>`   | -       | Hex color overrides (`colorBack`, `colorMid`, `colorHighlight`)|
| `paused`         | `boolean`                           | auto    | Freeze the frame loop (defaults to reduced-motion)             |
| `pauseOffscreen` | `boolean`                           | `true`  | Pause rendering while scrolled out of view                     |
| `maxDpr`         | `number`                            | `2`     | Maximum device pixel ratio                                     |
| `className`      | `string`                            | -       | Wrapper CSS class                                              |
| `style`          | `CSSProperties`                     | -       | Wrapper inline styles                                          |
