**shadercn** provides beautiful, customizable GPU shader effects as React components. Built on [vgpu](https://vgpu.labs.vercel.dev/) and [typegpu](https://typegpu.dev/), and designed to work seamlessly with the [shadcn CLI](https://ui.shadcn.com).

## Philosophy

shadercn follows the shadcn model for shader effects: copy-paste components you can own, with zero lock-in and sensible defaults that work immediately.

Shader effects are often treated as one-off snippets — scattered across forums, hardcoded with magic numbers, and difficult to compose. shadercn takes a different approach. Each shader is a typed React component with exposed props, runs on the GPU via WebGPU, and drops into any React framework.

The goal is simple: make GPU-accelerated visuals feel like the rest of your stack — composable, themeable, and easy to customize.

## Why shadercn?

Most shader setups are either too low-level or too opinionated. shadercn is built for teams that want to ship quickly without giving up control:

- **Own Your Code:** Copy the components into your project and customize everything.
- **Start Fast:** Run one command and render your first shader with production-ready defaults.
- **GPU-Powered:** Runs on the GPU via WebGPU for smooth 60fps performance.
