## Prerequisites

A React project with WebGPU support. shadercn components use [vgpu](https://vgpu.labs.vercel.dev/) as the shader runtime and [typegpu](https://typegpu.dev/) for type-safe GPU compute.

## Installation

Run the following command to add a shader component:

```bash
npx shadcn@latest add @shadercn/orb-01
```

Without a registry alias, use the full URL:

```bash
npx shadcn@latest add https://shadercn.run/r/orb-01.json
```

The registry installs the matching vgpu runtime and any required dependencies.

## Usage

Import the installed component and use it in your React app:

```tsx
import { OrbPreview } from "@/components/ui/orb-01";

export function Hero() {
  return (
    <div className="relative h-screen">
      <OrbPreview className="absolute inset-0" />
      <div className="relative z-10">
        <h1>Your content here</h1>
      </div>
    </div>
  );
}
```

## Customizing Props

Every shader component exposes its visual parameters as props:

```tsx
<OrbPreview speed={0.5} color1="#ff0000" color2="#0000ff" intensity={0.8} />
```

## Adding to Your Project

### 1. Install dependencies

```bash
pnpm add vgpu typegpu
pnpm add -D @webgpu/types
```

### 2. Install the component

```bash
npx shadcn@latest add @shadercn/orb-01
```

### 3. Use it

```tsx
import { OrbPreview } from "@/components/ui/orb-01";

export function MyPage() {
  return <OrbPreview />;
}
```
