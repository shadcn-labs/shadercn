We shipped the initial release of shadercn with 33 GPU-powered shader orb components for React.

- **33 Orb Shaders** — Unique animated shader effects ready to drop into your app
- **vgpu Runtime** — Built on the modular cross-runtime WebGPU library
- **shadcn Registry** — Install any component with `npx shadcn@latest add @shadercn/orb-01`
- **Fully Typed** — Every shader parameter exposed as a typed React prop
- **GPU Accelerated** — Runs on the GPU via WebGPU for smooth 60fps performance
